# Security policy

Ediflux moves business documents between companies, so we take security reports seriously.

## Supported versions

Ediflux has no release yet. Once it does, security fixes will go to the latest minor release.

## Reporting a vulnerability

Please **do not open a public issue**. Report the vulnerability privately through GitHub:
[report a vulnerability](https://github.com/imapanda/ediflux/security/advisories/new).

Include what you can of the following:

- the affected component and version (or commit);
- the steps or a proof of concept to reproduce it, with anonymized data only;
- the impact you expect (data exposure, message tampering, denial of service...).

Ediflux is maintained by volunteers. We aim to acknowledge a report within a week, agree on a
fix and a disclosure date with you, and credit you in the advisory unless you prefer otherwise.

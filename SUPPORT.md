# Getting help

Libredi is a young open-source project with no release yet, so help is best effort and public:
an answer given in a discussion helps the next person with the same question.

| You want to                                     | Go to                                                                                                                          |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Ask how to do something, or why it behaves so   | [Discussions, Q&A](https://github.com/imapanda/libredi/discussions/categories/q-a)                                             |
| Share an idea or a real-world EDI requirement   | [Discussions, Ideas](https://github.com/imapanda/libredi/discussions/categories/ideas)                                         |
| Ask about a partner's format or share a mapping | [Discussions, Partner formats & mappings](https://github.com/imapanda/libredi/discussions/categories/partner-formats-mappings) |
| Report a bug                                    | [A new issue](https://github.com/imapanda/libredi/issues/new/choose)                                                           |
| Report a security vulnerability                 | The [security policy](SECURITY.md), privately: never in a public issue or discussion                                           |
| Propose a change or a fix                       | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                                             |

## Before you ask

- Search the existing [discussions](https://github.com/imapanda/libredi/discussions) and
  [issues](https://github.com/imapanda/libredi/issues): your question may already have an answer.
- **Never post real partner data or credentials.** Anonymize company names, addresses, GLNs,
  prices and references, and remove passwords, private keys, certificates and tokens, in every
  message, log and configuration you share. The repository is public.
- Give the Libredi version (or commit), what you tried, and the exact error. An anonymized sample
  message and the mapping involved save everyone a round trip.

## What to expect

There is no support contract and no guaranteed response time. Maintainers answer when they can,
and other users are welcome to answer too. There is no commercial support at the moment.
